## Description of the Work

Smart Blockchain and AI-Based Healthcare System (BioChainAI 2.0) is an original, independently developed software system comprising:

### 1. Backend (Python / FastAPI)
A RESTful API server with WebSocket support implementing:
- Multi-role JWT-based authentication with OTP 2FA
- Blockchain smart contract interaction via Web3.py
- Decentralised IPFS file storage through Pinata API
- AI-powered clinical assistance via Google Gemini API
- Real-time vital signs simulation and WebSocket streaming
- PII encryption and secure data vault

### 2. Frontend (React / Vite)
A single-page application implementing:
- Role-based dashboard (Patient, Doctor, Hospital Admin)
- MetaMask Web3 wallet integration
- Live vitals monitoring with real-time charts
- Electronic Health Records management UI
- Drug interaction checker interface
- Appointment scheduling system

### 3. Blockchain (Solidity / Hardhat)
An Ethereum-compatible smart contract system implementing:
- On-chain patient record hash verification
- Access control and permissioned data sharing
- Immutable audit trail of all medical record transactions

### 4. Infrastructure
- Docker Compose configuration for containerised deployment
- PowerShell one-click launcher script
- Environment configuration templates
